# P4 Vault/Connector Scaffold (2026-11-23)

## Status
- Design/scaffold only; no live external connectors enabled.

## Added
- `packages/shared/src/connectors.ts`: `VaultSecretRef`, `CredentialBroker` interface, `ConnectorKind`, `ConnectorDefinition`, `ConnectorAccount`.
- `packages/shared/src/auth.ts`: session/auth context contracts for API session-token foundation.
- DB schema: `sessions` extended with `token_hash`, `user_agent`, `ip_hash`, `last_seen_at` (manual SQL patch applied locally; migration generation still blocked by drizzle-kit TTY issue).
- API: `POST /v1/auth/sessions`, `GET /v1/auth/me`, `POST /v1/auth/sessions/:id/revoke`; auth middleware accepts bearer session token or dev `x-user-id` fallback when allowed.

## Security invariants
- No raw secrets in task messages/events/logs; only secret refs/IDs.
- Connector execution must use approval+idempotency+receipt for side effects.
- Legacy unbound browser sessions remain hard-blocked; explicit rebind endpoint requires owned task and emits audit/event.
